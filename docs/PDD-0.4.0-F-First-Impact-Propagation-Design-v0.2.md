# PDD 0.4.0colFix2 — F 선배분·충격 법선 검증·탄성 경로 분리 설계 v0.2

**2026-11-05 · colFix2 개발 규칙 (v0.1에 대한 구현 전용 구체화)**

## 우선순위·버전 경계

1. PDD 통합설계서 1.0.6의 0.4.0 안전 경계를 유지: 충돌/재료/손상/변형/파괴는 **Preview 계획 전용**, WORLD/Plot 실제 변경 OFF. 0.4.1 World 안전 커밋, 0.5.1 Plot 안전 커밋, 0.6/0.7 응력·변형/시각화 단계의 임의 조기 구현 금지.
2. 사용자가 확정한 F 먼저 배분→블록마다 Q 변환→탄성체가 선행 블록 Q와 후속 F 감소→실제 종단이 남은 F 전액 인수→같은 충돌/소유 공간 내 블록당 처리 1회 계약 유지.
3. colFix의 이전 BFS 층별 평균 탄성과 6방향 무제한 지형 탐색은 게임 신뢰성 문제가 확인됐으므로 **공통 WORLD/Plot 전파 계획기에서 대체**한다.
4. Sable의 원본 물리·접촉 콜백, read-only 관측, 원인 Credit·중복 제거·월드/Plot 소유권 및 좌표 검증, Q 상한·저장 계약을 보존한다.

## Sable 방향 증거 — 실제 2.0.6 JAR 계약

- Sable 2.0.6 내장 `Rapier3D.clearCollisions(long)`는 `[D`, `RapierPhysicsPipeline.processCollisionEffects()`는 15필드 레코드의 `[3..5] localNormalA`, `[6..8] localNormalB`, `[9..11] localPointA`, `[12..14] localPointB`를 소비한다. 원래 consumer의 배열은 반드시 **그대로 반환**한다. 이 API는 정확한 `impulse`나 `substep ID`를 제공하지 않는다.
- Sable Rapier의 `local_n1/local_n2`는 **원본 충돌 매니폴드 법선 벡터**이다. Native effect는 사후 정보이므로 사건의 충돌법선 방향은 알 수 있지만, 개별 블록의 정확한 동일-substep 접촉 위치·임펄스까지 확정하지 않는다.
- WORLD(-1)는 원점 고정 World 지면 콜라이더에 의해 월드 기준으로 기록된다. Plot은 `activeSubLevels`의 실제 effect 소비 시점 pose를 캡처해 localNormal을 world normal로 바꾼다. 두 세계 방향의 내적은 -0.98 이하여야 한다. 해당 시점의 각 pre-solver pose 회전과 effect pose의 quaternion 내적 절대값은 0.995 이상이어야 한다. 서로 다른 매니폴드 레코드의 같은 소유자 법선 내적은 0.98 이상이어야 한다.
- 여러 레코드가 서로 충돌하거나 소유자/runtime ID/plot UUID/epoch/scale/frame이 불확실하거나 native event 100레코드 상한에 걸렸으면 `UNKNOWN`으로 강등한다. 이상 여부는 `[PDD-NATIVE-NORMAL]`에 출력한다.
- Plot/World에도 검증된 signed native axis (`abs(component)>=0.98`)면 `DirectionEvidence`에 기록하되 `sourceSubstep=-1`, `exactContact=false`, `deformationAuthorized=false`를 유지한다. 사선 native vector는 F 방향장에만 사용하고 격자 변형 방향으로 반올림하지 않는다. Plot/Plot 기존 보수적인 pre-substep 방향 게이트는 그대로 유지한다.

## F 선배분 — 자연스러움과 CPU 예산을 고려한 구체화

1. 승인된 각 사건의 F는 기존 정책대로 두 소유자 공간으로 50:50 나눈다. 미승인/소유 미증명 측에 임의로 다시 배분하지 않는다.
2. R2 실제 소유자 블록·충돌 형상 검증을 통과한 블록만 최초 씨앗이다. 최초 씨앗들이 동시 접촉했다면 F를 동일하게 나눠 주고, 이후에는 **부모별** F 흐름을 추적한다.
3. 미처리 유효 이웃이 있으면 현재 부모에게 1/2, 남은 1/2을 그 부모의 유효 자식들에게 균등 전달한다. 자식이 두 부모에서 같은 단계에 F를 받으면 **먼저 F를 합산한 뒤 Q를 한 번** 계산한다. 방문 블록은 소유자별 local XYZ로 중복 처리하지 않는다.
4. 탄성 전달율은 기존 버전의 개발 계수 `t(E)=0.15+0.85×(1−E/100)^1.5`. 각 탄성 블록은 **실제 부모들의 아직 확정되지 않은 Q**만 경로 분율로 한 번 감쇠한다. 자기 자신의 후속 전달 F에는 `t(E)`를 적용한다. 무관한 형제 경로는 감쇠하지 않는다.
5. 블록마다 계산한 Q는 별개 `DamageModel`에서 **자기 탄성에 의한 Q 흡수도 딱 한 번** 처리한다. 선행 Q 감쇠·후속 F 감쇠와 자기 Q 흡수는 서로 다른 예산 대상이며, 물성·그룹 상한 초과 또는 감소분을 다른 블록 Q로 재발행하지 않는다. `Q=absorbed+direct+plasticUnused+stressUnused` 내부 회계와 전체 Credit `issuedQ=plannedQ+unusedQ`를 보존한다.
6. 다음 유효 이웃이 *실제로 모두 없음*을 증명했을 때만 종단이며, 그 지점의 전파 잔여 F **100%**를 현재 블록에 할당한다. 미로드 청크, 물리 owner 혼동, 탐색 상한 또는 불확실한 방향은 물리적 종단이 아니다. 탐색 깊이 제한에 닿아도 다음 셀을 읽어 실제 종단인지 확인한다.
7. 증명된 native 법선의 *소유자 내부 방향*에 따라 처음 이동 방향(회전 포함)을 선택하고, 전체 씨앗으로부터 앞으로 `perpendicular² <= 0.36×forward²`인 좁은 전파 원뿔을 허용한다. 사선 법선의 첫 격자 이동을 놓치지 않도록 방향 성분 0.5 이상인 첫 블록 이동을 허용한다. **뒤쪽 전달 금지**. 이는 법선은 실측 native 방향이지만 확산 각도는 PDD 게임 정책임을 뜻한다.
8. Native 법선이 불명확하면 depth 0,1,2까지만 탐색하는 비방향성 Preview로 강등한다. verified native 방향 경로도 최대 depth 9, 한 side 최대 128 블록으로 제한한다. 전달 F가 Q 변환 유효 floor 이하로 작아진 경로는 더 이상 영 의미 있는 블록을 탐색하지 않는다. 이때 남은 F는 `unresolvedF`이고 마지막 블록에 몰아주지 않는다. 방향장/노드 수/깊이 한계는 파괴 임계치나 물리 원리를 뜻하지 않는다.
9. 예산이 커도 Q는 기존 `forceGain=0.161`, `forceFloor=2.0`, `maxGroupQ=65536`, `damageGain=2.6`, 원인당 50:50 그룹 Q 상한에 따라 봉인한다. F는 유한·비음수, Q는 유한·비음수, 양자화는 기존 1/256 소수 손상 저장을 따른다.

## 슬라임의 피해 규칙

- 확정된 Sable 물리 반발은 PDD가 변경하지 않는다. `H=0`, `D=80`, `E=100`을 유지하면서, Vanilla `minecraft:slime_block`의 T는 **최소 64**인 개발용 내구도 보정값으로 정한다. 기존 기본 T=1은 작은 Q도 즉시 파괴하도록 만든다. 사용자 material override 정책이 마지막 우선권을 가진다.
- 자기 `Q`의 내성은 `DamageModel`에서 `t(E)` 완충을 한 번 거친 뒤 경도·연성·피해 임계치로 독립 계산한다. `E=100`에서도 `t(100)=0.15`이므로 무적이 아니다. 기존 분리·재접근 검증을 통과한 재충돌은 별도 Credit으로 누적한다.

## 회귀 필수 조건

- 5블록 선형 경로는 탄성 없을 때 `F=[50,25,12.5,6.25,6.25]`(한 측 F=100). 다른 소유자에 같은 로컬 XYZ가 있어도 서로 중복되지 않는다.
- 동시 접촉·분기·합류는 F 추가 발행 없이 블록별 한 번만 처리. 형제의 탄성은 서로의 Q를 감쇠하지 않는다.
- 실제 3단 돌–슬라임–돌의 중간 슬라임은 선행 돌의 잠정 Q와 후속 돌에 전달되는 F 모두를 낮춘다. 슬라임의 자기 흡수도 적용하며 T=64로 미세 충돌 즉시 파괴를 방지한다.
- 광대한 WORLD 잔디 평면은 수평 무제한 탐색/128개 반복을 회피하고 방향 증거에 따른 유한 전파. 증거가 없는 경우에는 원뿔 방향을 꾸며내지 않는다.
- native 법선의 반대 방향·소유자·최소 회전 증거 불일치 시 `UNKNOWN`. 사선은 실측 방향 벡터를 그대로 유지하고 미검증 격자 변형을 거부한다.
- 월드 블록/Plot 실제 손상·변형·파괴/드롭/BE 변경, Sable solver/callback 동작 **모두 0.4.0에서 비활성화·변경 금지**. 0.4.1 안전 World commit은 별도 요구 사항과 검증을 통과한 뒤 진행한다.

**검증 상태:** 설계에 대한 정적 구현 규칙. Java/독립 계산 검사를 통과해도 실제 Gradle/JUnit·Actions·인게임 방향성 및 충돌 정확성은 별도 검증 대상이다.
