## Test environment
Minecraft Java 1.21.1; Java 21; NeoForge 21.1.228 or later compatible 21.1.x; Sable 2.0.6; Create 6.0.10; Create Aeronautics bundled 1.3.2; and **only one PDD JAR, version 0.2.12**.

## Tests to perform in order
1. **T0 Build and load** — In GitHub Actions `PDD Manual Build`, verify `Run JUnit tests` and `Build JAR` succeeded. Note: its protected artifact title may still be `PDD-0.2.11-debug`; the actual JAR inside should be `physical-destroy-deform-0.2.12.jar`. At startup find `[PDD-DIAG] INIT ... version=0.2.12` and `[PDD-DIAG] SABLE_BRIDGE ...`. No `MixinApplyError`, `InvalidInjectionException`, `NoClassDefFoundError`, `NoSuchMethodError` or `ClassNotFoundException`.
2. **T1 Ordinary stone** — Using an Aeronautics/Sable physically simulated moving structure of normal stone, collide slowly with stationary natural stone terrain, then repeat more quickly. Compare 100-tick summary: `wrappedNull` should increase when standard blocks are baked, `callbackInvocations` should increase when contact reaches JNI callbacks, and `[PDD-RAW] ... original=false` should appear. Note: an increase in `wrappedNull` alone is *registration*, not an observed collision. The moving structure must genuinely contact, not just visually overlap.
3. **T2 Ordinary wood + other type** — Repeat with planks and a different block (e.g. cobblestone); sample `block=<block_id>` should match what was baked. Compare early/late/diagonal hits.
4. **T3 Special behavior** — Cause genuine contacts with Sable Fragile, Belt and TNT-specific callback blocks. Search `[PDD-RAW] ... original=true` with callbackType. Compare fragile/TNT destruction behavior and belt movement response with **PDD 0.2.12 removed** in an otherwise identical world. Original callback should execute once; no extra block breaks, duplicate effects or altered motion.
5. **T4 Ship–ship** — Collide two Aeronautics structures, first slowly then quickly; inspect native and raw counters. Do not conclude raw coordinates are world-space, or add both feeds to compute damage.
6. **T5 Idle and load** — Leave a docked/inactive ship for ~30 s, then repeat a collision. Observe queue bounds (`rawDropped`), `captureErrors`, server performance, game freezes and persistent `NO_CALLBACK_OBSERVED` with actual impacts. Block damage and visible crack overlay should remain absent (intentionally unimplemented).
7. **T6 Optional addon compatibility** — Re-run T1/T3 individually with True Impact 0.5.7-delta, Sable Collision Damage 1.0.8, Sable Impact Alpha 1.1.0, Sable Optimizer 1.0 added as optional extras. Monitor Mixin collisions and changed native effects. **Do not enable all optional mods at once for the first baseline**.

## Acceptance criteria for G-COL-01
- Both ordinary collision and existing callback collision produce raw records, not just INIT or native effects-feed records.
- Original Fragile/Belt/TNT behavior is unchanged vs PDD-absent control, including motion and destruction results.
- No Mixin load failures or native exceptions; bounded logging/queue and `captureErrors=0` during test.
- If any fail, mark `G-COL-01` **FAILED / UNVERIFIED**, provide full evidence; never claim success from static analysis only.
