## Change and limits

Use the hit-side native frame to compute the world point; derive the other-side local coordinate only by transforming **from this point**. Compare independent, opposite-side callback world points in the same physics epoch. `matchingPairs`/`mismatchedPairs` accumulate only for adjacent reciprocal callbacks: they are not exhaustive counts for all collisions. Geometry tests with a 2-block tolerance are diagnostics, not proof of every Sable collision shape. World mutation remains disabled.
