## Implemented policy

1. Original Sable POST_EFFECT event, owner proof, positive separation, episode authorization, and single source envelope Q **unchanged**. Sable raw force remains a gameplay proxy, not SI force or true impulse. The envelope `Q = min(maxGroupQ,forceGain*max(0,F-forceFloor))` is retained solely as a per-event maximum; no previously-issued Q is reissued. `forceGain=0.161`, `forceFloor=2`, group cap 65536, damageGain 2.6.
2. On authorization, the source **F** is separated 50:50 into owner A and B. Missing owner evidence remains unused. For each side: R2 source-proven targets are initial seeds. A read-only six-neighbor BFS queries currently loaded blocks through the same owner and coordinate frame; WORLD is global, PLOT uses its verified Sable `ServerSubLevel` + `LevelPlot` center to translate from owner-local to allocated plot-grid positions. Unverified, unloaded, or changed owners do not manufacture downstream targets.
3. Each verified breadth layer receives half of its available F; blocks at the same BFS depth receive equal shares. A demonstrated terminal layer with all six neighbors accounted for receives **all** residual F. All F→Q conversions happen **individually** after F assignment. Nodes are visited at most once per owner side and credit, even on cycles, duplicate source points, or graph joins.
4. The current layer's elasticity uses the previous DamageModel transmission curve `0.15+0.85*(1-E/100)^1.5`. When the layer contains parallel blocks, their transmission is **arithmetic-mean** averaged. This reduces (once) the *immediately preceding breadth layer's still-provisional Q* and the next layer's F. It does **not** apply local elasticity to the current node again in DamageModel. Earlier stored damage never retroactively changes.
5. `MAX_NODES_PER_SIDE=128`, `MIN_REMAINING_F=1/256` stop expensive traversals. If a neighbor is UNKNOWN, the capacity is reached, or remaining F falls below minimum before proved terminal, **do not concentrate the remaining F on the last visited block**. Unallocated F is reserved as unresolved, not converted into Q. If the actual proved graph ends with a single or multiple blocks, the entire remaining F is distributed to that terminal layer. Proven contact seeds remain capped at 32 per side by existing R2 native-region rules.
6. The sum of per-block final Q is clipped to the event's preexisting 50:50 source Q envelope if necessary (e.g., saturation at large raw F); the delta is recorded unused. `Grant.issuedQ == allocatedA + allocatedB + unused` remains intact; `MaterialPlanner` and `PreviewDamageLedger` consume only the post-elastic individual Q shares. World/Plot damage preview, threshold and bounded sparse-state checkpoint use the existing code paths unchanged.

## Explicit provisional choices — NOT user-finalized physics rules

- **Branching / simultaneous first contacts:** equal F per same-depth target, then 1/2 for the next breadth layer, not native contact record array order. This preserves equal contact treatment and finite budget without fabricating a direction. Future design may replace it after establishing native per-contact signed normal/contact timing.
- **Elastic predecessor range:** immediately previous breadth layer only; parallel elastic material transmissions are averaged; one application per layer. The user's v0.1 design did **not** specify branch-specific Q backpropagation or the precise attenuation formula. Those are replaceable gameplay policy choices, not proved Sable physics.
- **Non-directional connectivity:** six block-face neighbors in owner-local coordinates. This is not the later 0.6.0 Q-stress subsystem and must not also reissue its budget as separate stress Q. Unbreakable or block entities receive the same read-only preview audit; no unsafe block movement is attempted.
- **Verification boundary:** parent Sable/Minecraft/neoforge binaries and dependency configuration were not altered. Local standalone Java type compilation and pure tests are **not** proof of Gradle full compile, JUnit, actual NeoForge server load, or game correctness.
