## Actual changes

1. `NeoForgeWorldGateway.java`: retain **no block ID allow-list** (slime, netherite and ordinary modded single-cell blocks are candidates) but restore intrinsic `getDestroySpeed()<0` veto, BlockEntity veto and linked vanilla multi-block veto. Null/air/owner/chunk/permission checks remain; real break uses `BreakEvent` and one `ServerLevel.destroyBlock(pos,true)`.
2. `WorldCommitCore.java`: use original immutable material definition for damage, not a forced `asBreakable()` copy. Protect material `unbreakable`, negative vanilla break speed and BE/linked structures in preflight before damage/break commit. Protected types produce an `ABORTED` audit receipt, but **no applied damage state, break or drop**.
3. `MaterialPlanner.java` / `MaterialProperties.java`: remove the World-only immunity bypass, preserving consistent `UNBREAKABLE_UNUSED` preview state for World and Plot.
4. Existing `WorldCommitCoreSelfTest`, `WorldCommitIntegrationTest`, `MaterialPlannerTest`: adjust regression expectations and explicitly check that ordinary `minecraft:slime_block`, `minecraft:netherite_block` and third-party block IDs can break, while material-immune, vanilla-immune, BE, linked structure, claims and cancellations cannot.
5. `build.gradle`: label this corrected source and manifest `0.4.1-Fix3` rather than the earlier stale `0.4.1-Fix2` label. NeoForge, Java and Gradle versions/dependencies unchanged.
6. `README.md`: correct the contradictory active World safety description and mark the Fix2 bedrock/BE bypass as superseded.
