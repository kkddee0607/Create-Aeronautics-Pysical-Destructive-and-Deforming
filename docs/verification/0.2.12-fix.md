## Binary ABI verification

Unzipped the **provided** Sable NeoForge JAR's nested Rapier module. `RapierVoxelColliderBakery.buildPhysicsDataForBlock(BlockState)` invokes `BlockWithSubLevelCollisionCallback.sable$getCallback(BlockState)` and forwards that exact result into `Rapier3D.createVoxelColliderEntry`. The Sable callback interface exposes `onCollision(6 int, 4 double, boolean):double[]` and `sable$onCollision(BlockPos,BlockPos,Vector3d,double):CollisionResult`. `CollisionResult.NONE` statically reads `sable-companion` `JOMLConversion.ZERO`, which is why JUnit needs the explicit Companion dependency even though the game JAR bundles it. No new Maven dependency was added by `0.2.12-fix`.
