## Actual binary proof, not a guess

```text
javap -c -p BlockSubLevelCollisionCallback$CollisionResult
static {}:
  getstatic dev/ryanhcode/sable/companion/math/JOMLConversion.ZERO
  invokespecial CollisionResult.<init>
```

The **provided Sable NeoForge JAR** contains `META-INF/jarjar/sable-companion-common-1.21.1-1.6.0.jar`, and that inner JAR contains `dev/ryanhcode/sable/companion/math/JOMLConversion.class`.

A standalone Java 21 smoke check compiled PDD's real `ObservingCollisionCallback`, `RawObservation`, `SableContactQueue` against the supplied actual Sable classes and minimal Minecraft/JOML stand-ins:

- Without the original bundled Companion JAR: **reproduced `NoClassDefFoundError: dev/ryanhcode/sable/companion/math/JOMLConversion`** at `CollisionResult.<clinit>`.
- With the original bundled Companion JAR: **PASS**, direct callback original invoked once, same `CollisionResult` object returned, exactly one observation captured.

This isolates the missing runtime class, but **does not substitute for real Gradle/JUnit or an in-game NeoForge test**.
