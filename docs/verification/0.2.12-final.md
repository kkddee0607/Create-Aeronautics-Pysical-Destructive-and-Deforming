# PDD 0.2.12-final — contract ledger

Design: PDD Integrated Design 1.0.1 §14.1–14.2. Source base: public GitHub main, SHA `8bfabca4973bcad625838e3ee92ef04f5236d655`.

## Implemented in the source-overlay package
- Wrapped Sable original callback at `RapierVoxelColliderBakery.buildPhysicsDataForBlock` expression with `require=1` and mandatory Mixin config.
- Original invoked exactly once; native `double[]` object and high-level `CollisionResult` returned without modifying it. Any original exception propagates unchanged.
- Ordinary non-air blocks with null callbacks get a neutral observer; this changes the JNI callback-present branch and requires PDD-disabled physical regression to approve.
- RawObservation retains original source label, owner/frame *unknown* placeholders, nano timestamp, block ID, callback type, hit/other raw coordinates, raw point/velocity and result flag.
- Bounded thread-safe `SableContactQueue` measures intake, overflow, capture error and original/null registration counts.
- Server tick drains the queue and dispatches raw observations to a concrete `CollisionAcceptanceMetrics` consumer and a 0.2.13 extension port; neither logs nor Sable effects feed are authoritative impacts.
- Existing NativeCollisionTelemetry is preserved as auxiliary metrics only.

## Explicitly NOT claimed
- End-to-end game acceptance `G-COL-01`: pending real stone/wood↔ship, Fragile/Belt/TNT tests with control run without PDD.
- Null-branch JNI parity, as it cannot be proven from unit tests or a static read.
- Full NeoForge Gradle/JAR build: network/downloading latest GitHub source from the local runtime was blocked.
- Coordinate/owner/velocity normalization, mass, damage and mutation: intentionally deferred to 0.2.13 onward.

## Install/merge procedure
This is a source overlay, not a complete repository ZIP. Restore the other unmodified files from GitHub `main` at the stated SHA, then replace the included paths. Do not upload this overlay alone into a workflow that deletes missing project files. Do not claim a successful JAR build until CI passes.

## Gate checks
1. `./gradlew clean test build --no-daemon` with JDK 21 and the Sable/Create/Aeronautics dependencies.
2. Verify correct mandatory Mixin application; no `InvalidInjectionException`, `MixinApplyError`, `NoSuchMethodError`, or `ClassNotFoundException`.
3. Ordinary stone and wood vs moving Sable structure: `nativeCallbacks`, `stone`, `wood` must increase (not merely `wrappedNull`).
4. Fragile, Belt, TNT: `original`, `fragile`, `belt`, `tnt` must increase on the relevant scene, and PDD-on vs PDD-off physical behavior must match.
5. Confirm bounded queue drop counters and consumer counters behave under saturation. The raw feed must be available independent of verbose logging.
