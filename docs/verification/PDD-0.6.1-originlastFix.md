## Implemented contact contract
- `SableConsumerTargets`/`SableContactRegions`: independent owner-local native points, plot rotation-point translation once, cached actual owner and collision shape, unique block evidence only. An exhaustive multiple-block candidate set is not promoted to Layer 0. Independent raw local normal can disambiguate shape identity, never directly authorize a move. Native witness world-distance, PRE pose and dominant-axis geometry do not gate direct identity; they remain relevant to appropriate geometry/episode/direction checks.
- `SableContactRegions.Prepared`: direct result first; optional closed bilateral expansion is lazy and memoized. Live bridge requests it after authorization and before F sealing. Exception: when neither side has direct evidence, a credible pre-existing authorization/approach may request closed geometry to supply the initial target; ordinary unapproved/repetitive contacts do not run full expansion. Same batch/owner cache used. No unilateral footprint, halo, speculative pending target, rematch or patch-frame path remains. Existing direct evidence retained even if optional geometry fails. Geometry additions require both actual shapes, exterior faces, positive overlap, and a closed component; incomplete exterior cannot be cached as a known noncontact. Previously certified components survive unrelated incomplete components; failed components are not repeatedly traversed within the same frame group.
- `ContactCreditLedger`: validated direct/certified seeds and material-only opposite candidates separated through the existing Region model. One canonical credit; no intermediate Q grant. Per-side F = event F/2; unique seed denominator includes reserved possible distinct cells. Exhaustive ambiguity uses the union of possible cells minus already confirmed seeds; unbounded/unknown evidence is conservatively held using the bounded possible native-cell count (unknown identity may over-reserve, never become a damage seed). An exhausted owner remains quarantined. Missing/mixed E is withheld; same-E consensus allowed only across the complete opposite set. Live snapshot validates owner/block fingerprint before material lookup. Reentrant issue guard; no reallocation of held F to confirmed roots. A late independently certified other side can use only its own original half-Q envelope. Legacy entry points preserve historical test-facing candidate coverage and allocation contracts. Existing F/Q conversion, damping, propagation, Q cap, material properties, persistence, world mutation, stress and callback contracts unchanged.
- `TargetDirections`: remove unilateral geometry movement proofs. Only independent verified native direction and valid paid propagation edges can confer movement evidence. New certified geometry-only roots do not get invented move directions. Regional reimpact is evaluated using current native-direct cells against all previously credited cells (including certified expansion) and retains existing approach/episode gates. Shadow OBB/PRE diagnostics in DEBUG/TRACE only. Diagnostic `DIRECT_SEEDS`, `CONTACT_COVERAGE`, `CONTACT_SEED_SEALED`, `F_CREDIT_SUMMARY` identify coverage and reservations; aggregated event logs are still proportional to approved/attempted expansions, not a strict global cap.
- Deleted `ContactFacePatch.java` and `ContactFacePatchTest.java`. Deleted only tests of the removed unilateral implementation (23 declarations); seven retained test files updated to assert current contact contract; added 10 tests in OriginLastFixContactTest and 1 in FinalFixContactSurfaceTest. 828 -> 816 @Test declarations, 130 test Java classes/files. No test disabling or relaxed assertion tolerance. `check-duperfix-contract.py` exact inventory updated; `check-superfix-assertions.py` now detects obsolete runtime paths and direct seed/expansion/seal wiring. Gradle wrapper, dependencies, Java21, NeoForge21.1.228, JUnit5.11.4 and all Actions unchanged except release metadata in build.gradle/README/mod TOML. No save schema change. ## Remaining limitations
- Genuine ambiguity, unloaded/missing shape, mixed E and stale owner/material still withhold F by design. Unmapped points may conservatively reserve more cells than actual contacts; no guessed target. Sable cap may omit contacts; arbitrary rotated/oblique complete surface reconstruction is not guaranteed. Earlier certified aligned-face algorithm kept; no widening unproven tolerances. A real solver-substep calibration remains unavailable. Stress no-progress/TTL and Sable TCP/UDP tracking race and Copycat external registry selector are separate problems, intentionally not rewritten. No empirical performance or crash-free claim.
