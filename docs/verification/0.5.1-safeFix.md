## Changes

1. `WorldCommitCore.WorldGateway.deferBreakReason()` introduces a **read-only pre-PREPARED veto**; default null means that existing static-World behavior is unchanged. Both before permission events and after the canBreak event, a deferred Plot break retains its original ApplyId and durable `DEFERRED` Receipt. It is revalidated on a later tick with the same Q/material/fingerprint/owner. Bounded TTL expires to `ABORTED`, never replayed after restart.
2. `WorldCommitCore.tick()` processes at most each currently queued candidate once per tick; a held Plot cannot spin through the queue multiple times in one tick. The existing bounded operation cap is preserved.
3. New `SableHeatMapSafetyAccessor` is read-only Mixin `@Accessor`s for Sable **2.0.6** `SubLevelHeatMapManager` fields verified by `javap`: `initialized`, `splitComplete`, `floodfill`, `removed`, `newStarts`, `subLevelSplits`. A structural break is deferred until the live owner is verified and all Sable pending HeatMap collections are empty with completed initialization.
4. `NeoForgePlotGateway` serializes PDD break attempts per original `(dimension, UUID, generation)` with a minimum **3 server-tick** interval (configurable `pdd.plotBreakSpacingTicks=2..40`). Failed native API attempts also occupy one cooldown slot. No extra Sable remove/assemble/physics calls are made. The owner history is pruned after 1200 ticks of inactivity.
5. Bounded `[PDD-PLOT-SAFE]` diagnostics record actual owner/runtime ID, HeatMap state and why the break was deferred. `PDD-PLOT phase=SUMMARY` includes hold counts.
6. All existing `0.5.1-moreFix` Witness, durable Receipt, World damage and Plot damage paths remain. World and Plot Q/damage constants and test expected numerical values were not changed.
