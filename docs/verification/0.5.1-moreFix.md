# PDD 0.5.1-moreFix — Plot mutation witness and receipt correctness

Baseline: GitHub `main` `3f249e9437362a0a8d745cd1db179126422da2d5` (2026-11-13 UTC), IDS 1.0.8 §24.3–24.4 / §35.3; source: PDD 0.5.1-Fix GitHub Apply ZIP. Target: Minecraft 1.21.1 / NeoForge 21.1.x / Create 6.0.10 / Aeronautics 1.3.2 / Sable 2.0.6.

## Problem, proof and correction

Test log: `PDD-PLOT-REREAD status=OWNER_OR_CHUNK_UNAVAILABLE reason=SUBLEVEL_REMOVED apiResult=true` occurred after successful destroy API calls. `ServerSubLevel` disappearance alone does **not** prove that the requested block changed. Before this fix the PREPARED receipt remained `PARTIAL_QUARANTINED` because `readIfLoaded` required the original owner to survive.

The existing `WorldBlockReplacementMixin` targets the `RETURN` of `LevelChunk.setBlockState`; `EmbeddedPlotLevelAccessor.destroyBlock(BlockPos,boolean,Entity,int)` in Sable 2.0.6 delegates to `Level.destroyBlock` on center-offset allocated grid coordinates. `PlotBreakMutationWitness` now scopes a single attempted break to the exact server level, allocated block position, and original BlockState. Only a successful completed chunk mutation from that state to AIR, still AIR at the end of the call and with no block entity, yields witness proof. The ThreadLocal is removed in `finally`. The normal owner and Sable native physics callbacks remain unchanged.

`WorldCommitCore` promotes owner-unavailable readback to `APPLIED_BREAK` **only if API=true and the specific witness matched**. If false API or exception accompanies a witness, old incarnation state is durably invalidated but the receipt is quarantined; no automatic retry, manual drops, or speculative split transfer. An observed non-AIR reread also remains quarantined, even with a witness. Existing normal AIR readbacks, BE veto, claim protection, deferred recovery, split quarantine and WAL ordering are preserved.

Diagnostic: `[PDD-PLOT-WITNESS] phase=CONFIRMED_BLOCK_TO_AIR result=APPLIED_BREAK source=LEVEL_CHUNK_RETURN`. Presence of the diagnostic demonstrates Java-side block mutation, **not** Sable native mass/collider/COM upload completion. If the Mixin does not observe a legitimate break, the conservative old quarantine remains.

## Numerical and regression policy

- No modification to F/Q, T1024, hardness, ductility, elasticity, stress, cap, or damage threshold constants. Arbitrary changes to make tests pass would be invalid.
- `WorldCommitCoreSelfTest`: 44 assertions passed under isolated Java 21 `javac`/`java`.
- `WorldCommitReadbackFixTest`: 9 annotated test methods executed via a lightweight isolated Java assertion harness (not the official JUnit runner), including 4 new witness cases. Expected durable incarnation generation is **1** for a freshly proven changed cell; the receipt is `APPLIED` only on API=true + matching witness or ordinary AIR reread.
- Actual `./gradlew clean test --no-daemon`, `./gradlew build --no-daemon`, GitHub Actions, and in-game runs: NOT RUN here. Build success or native correctness must not be inferred from isolated tests. Existing Gradle Wrapper and workflows are Apply-protected and left unchanged.

## Remaining evidence and in-game procedure (maximum two sessions)

**Session A — normal Plot break and removed owner:** Back up the world. Use one small Plot and a two-block Plot, each with an ordinary non-BE block. Cause PDD collision damage until destruction. Expected: genuine AIR reread or `PDD-PLOT-WITNESS` with an `APPLIED_BREAK` receipt; no second break/drop for the same ApplyId. Deliberately break a Plot's last block and check whether `SUBLEVEL_REMOVED` occurs and whether witness is recorded. With no witness, quarantine without retry is expected; investigate before weakening the gate. Verify physical mass/collider in-game separately.

**Session B — split, restart, and network:** Split a partially damaged Plot, save, return to menu, and reload within the same game JVM. Observe UUID+generation, `ORPHAN_QUARANTINE`, and checkpoint/restore counts; new fragments must not inherit old-owner damage. Enable `-Dpdd.tracePhysicsLifecycle=true -Dpdd.traceSublevelPackets=true` for extra diagnostics. Check Sable native COM crash absence, but do not claim COM verified from PDD Java mass readings. Collect `latest.log`, SableBridge_Logs and any crash report on failure.

The Android S21 TPS/FPS limitation is excluded from PDD defect assessment. The previous Sable Optimizer COM panic, Sable movement packet timing, native COM/collider upload, and native collision source truncation remain independently unverified.
