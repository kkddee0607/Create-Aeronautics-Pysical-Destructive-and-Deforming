## Implementation

1. `collision/RealFixRuntimeBridge.java`, `collision/RealFixBoundsEvidence.java`: Plot/World rearm no longer uses the stale, previously verified World block AABB; only a complete bounded `confirmedWorldClearance` authorizes separation. Plot/Plot structural AABB rule unchanged. R4 diagnostics use separate max 128 checks/tick so they cannot starve the pre-existing max 1,024 positive-clearance checks/tick.
2. `collision/RealFixRuntimeBridge.java`, `collision/SableContactRegions.java`: use existing FSM evidence before expensive R2. Exhausted `ACTIVE` episodes skip shape inspections, not event collection, owner/generation validation, FSM processing or future separation. Skip is `SKIPPED_DUPLICATE`, never falsely counted as target rejection. `ARMED` and unspent `ACTIVE` states remain fully audited. Counters `r2Audits`, `r2SkippedDuplicate`, `r2ActualShapeChecks` added to periodic summary.
3. `collision/ContactCreditLedger.java`, `collision/SableContactRegions.java`: side verified target cap 4→32, region cap 16→64, per-side *new* unique shape lookup budget remains 32. Existing source, target identity, fingerprint, group Q (max 64), split and unused logic untouched. On one-sided exhausted/incomplete audit, quarantine only affected side and leave corresponding Q unused. Never pay just the first arbitrary N blocks.
4. `diagnostics/NativeCollisionTelemetry.java`, `collision/NativeContactMassEpoch.java`, `collision/RealFixRuntimeBridge.java`: carry scene-wide `clearCollisions` exactly-100-record saturation metadata from capture through COM masking to per-group logs. Native Java/Rust ABI stays untouched; zero PDD queue drops do not establish zero native truncation.
5. `PhysicalDestroyDeform.java`, `build.gradle`, `src/main/resources/META-INF/neoforge.mods.toml`, `README.md`: update runtime, package and log version to `0.3.1realFix`.
6. Tests: `ContactCreditLedgerTest`, `SableContactRegionsTest`, `RealFixBoundsEvidenceTest`, `NativeContactMassEpochTest`, `NativeCollisionTelemetryTest`. Keep every existing test; no test deleted, disabled or ignored.

**Explicitly not modified:** original Sable callbacks, JNI, R2 body-local Plot transforms, COM epoch acceptance, R3/R4 credit denial, original FSM credit eligibility and 50/50 allocation; `worldMutation=OFF`. No new external dependency.

## Two-session game acceptance procedure (same scene)

### Session 1 — Plot (B1) vs static World (A1 stone wall / A2 grass)

**Prerequisites:** only newly built 0.3.1realFix JAR in mods; Sable 2.0.6, Create 6.0.10, Aeronautics 1.3.2, NeoForge 1.21.1; server debug default `PDD` on; world mutation OFF; no unrelated PDD jars; start with enough physical clearance to observe two confirmed separated frames. Keep full `latest.log` from world start.

**Procedure:** (a) B1 hits A1. (b) Maintain sliding contact across adjacent World blocks **without actual Plot/World disengagement**. (c) Move B1 fully away from all World colliders for at least two independent positive clearance observations, then strike again. (d) Repeat B1 against A2 grass.

**Expected logs:** `PDD-OBS`, `PDD-NATIVE-TARGET`, `PDD-VERF-FSM`, `PDD-EPISODE`, bounded `PDD-LEDGER`; duplicate events now show `SKIPPED_DUPLICATE` and no shape checks/Q. Sliding over a *previously struck* World block must **not** produce `PDD-VERF-SEPARATION source=OBSERVED_AABB_GAP` for a Plot/World pair; verified actual clearance prints `source=VERIFIED_WORLD_CLEARANCE`. After two positive confirmations, new genuine impact may mint **one** Q≤64 per episode. With 5–32 verified cells, no `TARGET_LIMIT_A/B` caused solely by original 4-cell policy. Exactly 100 raw native records prints `sourceCapSaturated=true`, not alleged native dropped count.

**Pass/fail:** no false rearm during continuous slide, no duplicate Q, no fabricated target on unloaded cells; returned Q shares + unused equals Q. Large/unknown clearance safely suppresses rearm, not crash. A failed module log or `INVALID_BRIDGE_INPUT` is a fail requiring full stack trace.

### Session 2 — Plot B1 vs Plot B2 (balloon) and B3 (stone Plot)

**Procedure:** Strike, hold contact, separate structural AABBs, strike again; turn/rotate and contact 5–32 different surface blocks if practical. Keep both Plot UUIDs in logs; optionally test changing COM (add/remove masses) while moving.

**Expected logs:** owner-local R2 verification, independent Plot IDs and block coordinates; no `WORLD_POINT_RESIDUAL_GT_0.25` global Q rejection; correctly preserved witness warnings. `PDD-LEDGER` one Q≤64 per valid episode; 5–32 verified block shares distributed without raising Q. `PDD-PLOTROG-EPOCH` if COM is unstable and mask only affected side. Native cap saturation is labeled. R3/R4 never mint Q.

**Pass/fail:** two separate Plot identities remain distinct; the same contact produces one credit; actual R2 block coordinates match viewed touched blocks; no phantom world mutation or crashes. Additional performance goal: `r2SkippedDuplicate>0` and reduced `r2ActualShapeChecks` relative to **similar contact conditions**, not necessarily exactly same as historic log.

### Evidence on failure

Provide complete `latest.log` with `PDD-DIAG`, `PDD-OBS`, `PDD-NATIVE-TARGET`, `PDD-VERF-SEPARATION`, `PDD-VERF-FSM`, `PDD-VERF-REGION`, `PDD-LEDGER`, `PDD-PLOTROG-EPOCH`, `PDD-PLOTROG-WITNESS`, summary including `r2SkippedDuplicate` and `sourceCapSaturated`, plus full GitHub Build and Callback Contract Actions failure logs and short statement of whether B1/A1/A2/B2/B3 visibly remained in contact.
