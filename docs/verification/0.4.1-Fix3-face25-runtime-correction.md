# PDD 0.4.1-Fix3: 25-cell face collision recovery and F ceiling

2026-11-08. GitHub baseline `main` `9e0b9911c19555d978c561c52207fc1316957022`.

## Observed problem

A 5×5×4 netherite Plot against a flat surface can result in sparse native contact witnesses near the four corners; the old face-patch gate required distinct preverified corner block keys and refused to scan the center. In-game evidence included `CORNERS_UNPROVEN`, `INSUFFICIENT_WITNESSES`, and `facePatchAddedA/B=0` despite verified contact regions. Merely changing JUnit boundary expectations had no effect on this runtime behavior.

## Runtime change

- `ContactFacePatch.reconstruct`: infer a bounded axis-aligned face rectangle from **four independently corroborated native corner witnesses**, not four prevalidated exact corner cells. Revisit each face cell individually using the *existing* `OwnerResolver.NativeAuditBatch` and reject any cell without verified owner-local collision shape, valid owner identity or consistent block coordinate. Require an actual previously R2-verified face anchor and individually shape-proved four corners; never infer a diagonal/oblique face or use old world-space pose for new credit.
- `SableContactRegions.audit`: preserves R2 and native snapshot, Sable original callback, contact sequence, one shared F/Q credit, existing 32,768 shape-read budget, 16,384 damage-target cap and 32,768 region cap. Logs recovered source seed counts and candidate face cells.
- `GameImpactCredit` existing production behavior: F uses `MAX_GAME_F=40,000,000`, with finite over-ceiling values *saturated* rather than rejected. F→Q is calibrated once per collision; do not issue 25 independent collision credits for a 25-cell face. `RealFixRuntimeBridge` adds `[PDD-F-CAP]` logging for a credited over-ceiling input. Both source-authorization and safety checks stay intact.
- Preserves inward-tapering F-first propagation, no extra F/Q accounting, materials, immutable unbreakable/negative mining speed veto, block entity and linked multiblock veto, claim / event veto and WAL for static World.
- Corrects internally displayed build version (`neoforge.mods.toml`, init and world policy) to 0.4.1-Fix3. Look for `[PDD-FACE-POLICY] revision=Fix3-FACE25` to distinguish this JAR from old Fix2-labeled builds.
