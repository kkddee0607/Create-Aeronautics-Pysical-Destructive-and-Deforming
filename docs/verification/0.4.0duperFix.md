# PDD 0.4.0duperFix — implementation, F/Q audit, and 2-session in-game verification

**Baseline**: GitHub `main` SHA `bc0267464f9ebd3f63f76a124979df2c549b642b`; 0.4.0superFix, 173 Apply-eligible files matched Git blob snapshots before changes. **Target runtime**: Minecraft Java 1.21.1 / NeoForge 21.1.x / Sable 2.0.6 / Create 6.0.10 / Aeronautics 1.3.2; **worldMutation=OFF**. **Design**: integrated IDS 1.0.7, the F-first 0.4.0 design, the approved four follow-up propagation rules, and the earlier ColFix3/SuperFix contracts.

## Resolution of the four requirements

1. **Mean native normal.** Each native Rapier manifold record must match the event's two owner IDs; each pair of owner-world normals must oppose (`dot <= -0.98`). Each owner's incoming vector is converted to its own effect-pose local frame and must round-trip. Unit vectors of valid records are summed once per owner and normalized (equal record weights, no unknown impulse weighting). `meanResultant=|sum|/N` and `minimumAlignment=min(dot(normal, mean))` quantify coherence. When meanResultant is below **0.10**, the direction is **UNKNOWN**, and no fake axis or native solver contact is inferred; null means an explicit nondirectional *equal-split* F fallback. Existing pre-solver effect-pose corroboration, native saturation and owner matching remain mandatory. Note: a single average is the stated policy, not a proven unique contact normal for disparate faces.
2. **No arbitrary depth end.** The runtime direction-aware 9/10-argument `ForcePropagation.plan` no longer stops at layers 2/9; all six-face owner-verified neighbors and the 30-degree forward cone are explored in a deterministic breadth-first DAG. A node is consumed once; concurrent parents are aggregated before calculating its Q. Work cap increased from **128 to 2,048 per owner**. Cap, unloaded/unknown neighbor or arithmetic overflow remain explicit **safety barriers**, not a fictitious terminal. These cases may legitimately return nonzero `unresolvedF` with `end=NODE_WORK_BUDGET`/`UNVERIFIED_BOUNDARY` and must not mutate the world. `MAX_UNKNOWN_DEPTH`/`MAX_NATIVE_DEPTH` in the runtime are no longer binding limits; the seven-argument legacy helper is retained solely for compatibility/regression, not used by the verified native runtime path.
3. **F/Q floor.** No F node or edge **below 1.0** propagates. The lost subunit F is counted in `thresholdDiscardF`; no local Q is emitted by a node whose incoming F is below 1.0. When a node's Q after path attenuation is **below 1.0**, its Q is zero and the amount is counted in `thresholdDiscardQ`. A final source event with provisional Q below 1 is not granted and does not consume the rearmed episode. The later per-side **Q cap** and per-node post-cap Q-floor are additionally applied in `ContactCreditLedger.seal()`, and the difference is reported via `[PDD-Q-SEAL]` rather than misclassified as `unresolvedF`.
4. **Verified terminal recuperation.** If all eligible adjacent successors have been checked and none is new, and no critical unknown/cap exists, a terminal node retains **all** its incoming F for its own local Q conversion. For `F=100`, 3 contiguous blocks, `E=0`: local F allocations `50,25,25`, terminal bonus `12.5` and transmitted F `50,25,0`. Only **outgoing** F is attenuated by the **current parent's** elastic coefficient; only *paid* child edges may attenuate that parent's pending Q. A blocked node receives its local half but its other half stays `unresolvedF`; it is not treated as a terminal.

**Policy decision**: `F<1` or `Q<1` means a zero *issued amount*, not that fractional quantities never existed. `thresholdDiscardF/Q` are accounting sink categories, while `unresolvedF` is an explicit safety diagnostic. Hence the auditable conservation equation is

`inputF = allocatedF + dampedF + thresholdDiscardF + unresolvedF`

and the pre-cap node Q equation is

`candidateQ = finalQ + dampedQ + thresholdDiscardQ`.

Source reservation is separate: `sourceIssuedQ = sealedA + sealedB + unusedQ`. `unusedQ` is not an error or a hidden mint; it includes honest differences from the global source Q envelope, elasticity, clamping, and per-block post-cap Q-floor. No source Q is duplicated across Plot and World.

## Audit log dictionary

All lines are plain server logger output; the exact numeric fields are defined here so a separate analyzer can validate them without guessing.

| Tag | Mandatory analysis fields |
|---|---|
| `PDD-NATIVE-NORMAL` | status, reason, records, ownerVectors, `meanResultant`, `minimumAlignment`, owner-local normalization policy |
| `PDD-NORMAL-SAMPLE` | effect-phase raw `nA/nB` local vectors, native bodies and frames, sample index; `PDD-NORMAL-SAMPLES` reports cap/suppression |
| `PDD-F-EDGE` | owner, parent/child coordinates, depth, parentReceivedF, parentLocalF, parentOutgoingF, directionWeight, actually `sentF`, local normal |
| `PDD-F-MERGE` | unique child, `parentCount`, `totalReceivedF`, `processedOnce` |
| `PDD-F-NODE` | node received/local/forwarded F, damped F, `recoveredTerminalF`, `thresholdDiscardF`, pre-cap candidate/final Q, counts, decision |
| `PDD-F-CUTOFF` | node/edge source, optional child, F rejected and precise reason (e.g. `EDGE_F_BELOW_ONE`, `SAFETY_UNKNOWN_NEIGHBOR`) |
| `PDD-F-LEDGER` | by owner: full F input/allocated/damped/unresolved/discarded, terminal bonus, Q values, nodes, depth, edges, merges, safety status |
| `PDD-F-INVARIANT` | both owner budgets and errors, `FStatus=PASS`, `QStatus=PASS` |
| `PDD-Q-SEAL` | pre-cap Q, per-side maximum, final sealed Q, Q dropped by source cap/per-node post-cap floor, unused source Q |
| `PDD-F-PERF` | graph wall-clock nanoseconds and max node cap (diagnostic measurement, **not** a benchmarking claim) |
| `PDD-F-TRACE` | per-event total records per type, emitted, suppressed, per-event/tick limits |
| `PDD-F-PLAN-REJECT` | reason for invalid/unverifiable runtime propagation; no credit is committed |
| `PDD-MATERIAL-PLAN/TARGET/TRACE` | material H/T/D/E, damage calculation and planned Q; per-tick number of suppressed material entries |
| `PDD-LEDGER`, `PDD-EPISODE`, `PDD-VERF-FSM`, `PDD-PREVIEW-SAVE` | original approval, duplicate suppression, generation, saved read-only preview state |

**Visibility/performance**: `-Dpdd.f.trace.enabled=true` is the verification default. Per-credit max **4,096** trace lines (`pdd.f.trace.maxPerCredit`), per-tick **8,192** (`pdd.f.trace.maxPerTick`); material plan up to **512** per tick (`pdd.material.trace.maxPerTick`); raw normal max **64** per credit (`pdd.normal.samples.maxPerCredit`), ordinary verification logs up to **1,024** per tick (`pdd.verf.maxLogPerTick`). Trace generation remains bounded and non-authoritative. Large collisions can still emit many log lines: use a copy of the world, adequate storage, and disable detailed logs once tests conclude.

## Local verification status and limitations

- Core Java21 independent compilation: **completed** for `ForcePropagation`, `NativeEffectDirection`, `GameImpactCredit`, `ContactCreditLedger` and their independent model/frame dependencies. This is **not NeoForge compileJava**: full runtime bridge requires external Minecraft/NeoForge API classes.
- Self-contained Java21 invocation of existing plus new source JUnit test methods with a local assertion runner: **68/68 passed** (after a test expectation about a nearly full safety cap was corrected from exact count to bounded count; the production algorithm was not changed in that correction). The runner uses a tiny local JUnit API shim; **not official JUnit 5 execution**.
- Actual `./gradlew clean test --no-daemon`: **not executed**; Gradle Wrapper/binary caches are unavailable locally. `./gradlew build --no-daemon`, `compileJava`, `compileTestJava`, `processResources`, and `jar`: **not executed**. GitHub Actions, actual runtime collision and world mutation: **not executed/verified**.
- Sable JNI/callback, Create/Aeronautics Mod APIs: no new external API calls or dependencies; existing reflection/source usage is unchanged. Jar availability does not imply validation of every external signature; official Actions check required.
- **Guardrail**: the requested absence of unresolved work cannot be **mathematically guaranteed** on large/unloaded structures or malformed owner evidence without fabricating proof. In these cases the code explicitly stops at a safety boundary and logs `unresolvedF`. The no-unresolved target is enforceable for completely proven connected regions below work caps and above the requested floors only.
- **Non-goals**: no active block removal, damage mutation, block physics reposition, breaking logic or reinforced deepslate balance changes.

## Two-session in-game acceptance protocol

### Session 1 — deterministic 3-block and multi-normal direction checks

**Setup**: one copy of a test world with the v0.4.0duperFix JAR as the only PDD mod, standard Create/Aeronautics/Sable versions and no stale conflicting PDD JAR; enabled high-detail logs. Assemble **3 aligned physically-connected stone blocks**, then a **mixed stone/slime/stone strip** as a separate structure. Make an unambiguous strike into a solid level World block, then rotate the structure and strike at 30–60° with visibly different contact faces. Record source timestamp and Plot ID. Re-hit after clear physical separation (do not count steady resting contacts as fresh impacts).

**Expected evidence**: approved `PDD-EPISODE` with `PDD-NATIVE-NORMAL` 1 or many records, a local normalized owner direction when a valid mean exists; `[PDD-F-EDGE]` sentF exactly matches `[PDD-F-MERGE]` per child, `[PDD-F-NODE]` child terminal bonus nonzero when all neighbors proven, and `PDD-F-INVARIANT` both PASS. With a 100-F synthetic lossless no-elasticity strip, expected F allocations are `[50,25,25]`. **In an actual Sable collision the source F is not fixed to 100 and stone is elastic**; compare ratios with E and F attenuation, never demand exact 50/25/25. A slime node must be present in `PDD-F-NODE` to claim slime buffering tested; compare its child transmission against stone-only path under similar conditions.

**Pass/fail**: incident accepted only when existing approach/separation and shape proof authorize it. At least one genuinely mixed-direction mean with 2+ different verified native normals is desirable to validate averaging live. If `AVERAGE_NORMAL_DEGENERATE`, `PLOT_NORMAL_LINEAR_FRAME_UNVERIFIED`, `UNKNOWN`, or `F-PLAN-REJECT`, **retain raw sample + frame logs** and mark averaging test inconclusive, not pass. No duplicated pair episode Q on sustained contact. No missing child F or Q budget; no `suppressed>0` during the selected clear case.

### Session 2 — radius ≈3.5 stone sphere with internal slime, high-F strikes

**Setup**: one connected sphere with **known Plot-local slime coordinates** documented by user for post-test analysis; ensure World and Plot contact blocks are loaded. Strike at multiple angles such that the sliding sphere may touch more than one surface face per event, with a bounce/re-separation between independent strikes. Include one stronger collision large enough to reach 130+ blocks. Monitor game TPS and logs; keep `worldMutation=OFF`.

**Expected evidence**: `[PDD-NATIVE-NORMAL] reason=AVERAGED_OPPOSING_NORMALS` for valid multi-face corroborated input, 2+ `PDD-NORMAL-SAMPLE` vectors that differ, `meanResultant` not degenerate; Plot `nodes>128` possible, `maxDepth>9` possible, `end=VERIFIED_TERMINAL` or `F_BELOW_ONE` for fully proven finite envelope; `thresholdDiscardF/Q` account for all tiny edges/claims; **targeted Plot-local slime** logged in `PDD-F-NODE` and `PDD-MATERIAL-TARGET` only if actual F/Q reaches it. If node limit 2,048, unloaded chunk, source evidence reject, or insufficient source F occurs, corresponding safety statuses are expected, not automatic algorithm failure.

**Success criterion for concluding 0.4.0 diagnostics**: choose at least one fully corroborated mixed-angle multi-block event with complete traces (`PDD-F-TRACE suppressed=0`), F and Q invariant PASS, neither owner `unresolvedF` above numerical noise, sensible terminal recuperation, child receipt sums matching payments, intentional `Q<1/F<1` suppression, and at least one mixed stone/slime owner-local path. **This is a criterion, not a claim of achieved in-game verification.** If it cannot be met, report the first rejection/unknown boundary and do not prematurely mark direction/world deformation verified.

**If any failure occurs, submit**: original full `latest.log` (not just excerpt), `crash-reports/` if crash, GitHub Actions `build`, `test`, `callback` job log, full `[PDD-EPISODE]`, `[PDD-NATIVE-NORMAL]`, `[PDD-NORMAL-SAMPLE]`, `[PDD-F-EDGE/MERGE/NODE/CUTOFF/LEDGER/Q-SEAL/INVARIANT/PLAN-REJECT/TRACE]`, `[PDD-MATERIAL-TARGET]`, relevant tick and Plot UUID. Capture server startup policy line (`PDD-POLICY`) and PDD version log.
