## Implemented changes

1. `mixin/RapierCollisionTelemetryMixin.java` and `diagnostics/NativeCollisionTelemetry.java`: immutable source-phase `OwnerFrame(UUID, Pose)` snapshot per native `id >= 0` from original `activeSubLevels`. `-1` remains an explicit static-collider sentinel, not a guessed Plot. Original `double[]` identity/content, callback behavior and post-effect order are preserved. Malformed data, drops and observer exceptions remain counted.
2. `collision/SableConsumerTargets.java` (new): bounded native R2 source-convention candidate; R3 independent other-side projection with same-record world-frame residual, max 8 boundary cells per side (epsilon 1/32), single owner-specific live block/shape audit. If candidates are 0 or 2+, **Q=0**; no arbitrary closest block, cross-dimension substitute or global Plot search. World `-1` candidate cannot pass without same-record Plot corroboration.
3. `collision/OwnerResolver.java`: stable UUID/Plot-chunk ownership cross-check, `EmbeddedPlotLevelAccessor` centered coordinate translation, loaded chunk requirement, actual collision `VoxelShape` proximity and block fingerprint; distinct Plot and static target keys.
4. `collision/RealFixBoundaryCandidates.java`: separate narrow native worldpoint-anchored R4 sampling (<=8) from legacy bounded full AABB diagnostics; large-AABB `SURFACE_SAMPLED` fake-target fallback eliminated. R4 is *always provisional* and cannot mint Q.
5. `collision/RealFixRuntimeBridge.java`: exact-phase owner resolution with valid pre-physics identity cross-check; grouped native 15-double raw records into pair/tick peak, no per-point summation; one-credit FSM unchanged. Attempt prior independently confirmed clearance on Plot↔Plot AABBs or bounded fully loaded Plot↔World air-space, never silence/timeout as separation. Source-correlated R2/R3 candidate targets for the event; callback-only R1 is a non-minting hint without source correlation. `PDD-NATIVE-TARGET`, `PDD-TARGET`, `PDD-EPISODE`, `PDD-SUPERFIX` logs contain rejection reasons and exact per-side mapping methods.
6. Three new native target/budget boundary tests (8 methods total across two new and one expanded test file) plus all legacy test files retained. Build `0.3.0superFix` metadata and README updated; `worldMutation=OFF` remains enforced.

### Known limitations and remaining risk

- Source-consumer agreement is not a collider-transform ground-truth calibration. A valid native record may still yield zero when world static collider geometry or rotated/multi-point owner mapping is unresolved; **no unverified target is elevated to verified** merely to force Q>0. The unverified R2 solver-frame inference is separately labeled `POST_EFFECT_CONSUMER_CANDIDATE`.
- Large Plot↔World pre-contact separation may be `UNKNOWN` because scanning the whole world volume would violate the bounded loaded-chunk rule. First contact can remain `INITIAL_CONTACT_UNKNOWN`; do not invent a successful new impact or relax the FSM without independent approach evidence.
- Source-owner pose snapshot is taken at the Java clearCollisions consumer phase; it is not an independently proven Rust solver substep collider snapshot. Multiple post-solver substeps can aggregate in one server tick. `nativeDropped=0` does not rule out the upstream Sable 100-record cap.
- No claims/mod veto or block-entity lifetime checks are needed for actual **mutation** here because this version never changes blocks; later-version commit must recheck them (§9 and §24).
- Existing Sable callbacks are not globally introduced to blocks where original callback was `null`; no custom callback factory override.
