# Source package status

This package is derived from the latest inspected PDD GitHub `main` source and PDD 0.1.3 API reference draft 3.3.1. It adds a startup diagnostic self-test around the existing API-independent models. It does **not** add Sable callback wiring or gameplay mutation.

The uploaded 0.1.2 ZIP did not include the Gradle wrapper; this package currently contains the 0.1.2 project files copied forward, plus the latest 0.2.0 diagnostic primitives and documentation. To provide a complete reproducible source export, the current GitHub `main` tree files are still needed for the wrapper and any newer project files. Do not treat this package as a production-ready or build-verified JAR.
